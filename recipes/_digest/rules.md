## DIGEST RULES (BINDING — shared by every research digest)

**Research live, never from memory.** Use **WebSearch** and **WebFetch** for everything. This
landscape moves faster than any training cut-off, and a confidently wrong URL is the one failure a
link list cannot survive.

**Verify every URL before you write it.**

- WebFetch every URL you publish. A 200 that renders the thing's own page is the bar.
- A redirect to a renamed, transferred or rebranded target is fine — publish the **final** URL.
- Anything that 404s, times out twice, parks, lands on a domain-sale page, or turns out to be a
  different thing than you thought is **dropped**, never guessed at.
- For a code repo, confirm it is **not archived** and has recent activity. Archived is a drop.
- Never state a version, date, price, star count or funding figure you did not read on the page.
- Prefer the apex or `www` homepage over a deep marketing path — deep paths rot first.

If verification drops you below the target count, go find more. **Never pad the list.** If you
truly can't reach the target, publish what you verified and say so in the intro line.

**Exact dates (`YYYY-MM-DD`) everywhere.** Never "last week" or "recently".

**Load `llm-writing` and `humanizer` before you write the entries, and run `humanizer`'s final pass
before you save.** Carve-outs, because those skills were written for an interactive session:

- **Skip their workflow and output steps** — no audit, no before/after report, no questions.
- **The entry shape in this prompt wins on structure.** The skills apply to the sentences inside it.
- **Watch repetition across entries, not just inside them.** Two dozen entries paraphrased from two
  dozen landing pages or READMEs is one sentence with the nouns swapped. Vary the opening — lead with
  the capability, the constraint, the odd design decision, who built it. Never open two consecutive
  entries the same way.
- **Never repeat a project's own tagline.** If the page says "the AI-native platform for modern
  teams", you have learned nothing; go find out what it actually does.

**Cover image.** Load `image-prompt-craft`, then write `cover_prompt` using the motif and the four
fixed colours this prompt names (name the colours in the prompt — they make the archive read as one
series). Vary the composition, focal motif and light from run to run, never the palette. No title,
no lettering, no numerals. The nouns this prompt warns about render their whole convention, invented
text and fake brand marks included, and "no text" will not stop them — describe the abstract motif
instead. End with the skill's constraint block, verbatim. The runner renders it at 16:9; don't put
the ratio in the prompt.
