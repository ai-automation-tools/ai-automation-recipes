Every recipe needs Claude Code. Covers are optional: a recipe renders one when `GEMINI_API_KEY` or
`OPENAI_API_KEY` is set and publishes without it otherwise. The **Also needs** column lists what a
recipe can't run without. A run that's missing one of those keys stops before the agent starts, so
it costs nothing.

When a recipe runs is up to you. Each Cronsole template ships with a default schedule you can change
on import. Which recipes have had a real run so far is tracked in the
[live-test status](../docs/ROADMAP.md#-live-test-status).
