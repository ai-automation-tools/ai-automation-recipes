# Vendored: claude-ai-music-skills

`.claude/skills/songwriting-craft/` is derived from
[bitwize-music-studio/claude-ai-music-skills](https://github.com/bitwize-music-studio/claude-ai-music-skills),
released under CC0 1.0 Universal (full text in [`LICENSE`](LICENSE)).

It is **not** a verbatim copy. The upstream material targets Suno; this version is retargeted to
ElevenLabs Music: syllable budgets are set against a composition plan's fixed `duration_ms`
sections, duration rows match the song recipe's targets, and the album-workspace assumptions were
removed. Don't "restore" it toward upstream.

This folder has no `SKILL.md`, so it is never offered to an agent as a skill.
