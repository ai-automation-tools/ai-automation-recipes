The recipes

One recipe, one automation

A recipe is a prompt, the skills it loads, a small Python runner and a Cronsole template. When it runs is your call: templates ship with a default schedule you change on import.

Boxed in

The agent can only write to its staging folder. Claude runs under --permission-mode dontAsk with an explicit tool allowlist, and anything else is denied.

No keys in the agent

The agent never holds a media key. It describes the cover or writes the composition plan, and the runner does the rendering.

Same run everywhere

Skills ship in the repo and are copied into each run, so a run behaves the same on every machine.

Any agent CLI

Claude Code is the default. Codex, Gemini CLI, OpenCode, Kimi Code and Grok Build each run through one JSON profile in core/engines/clis/.

Then python scripts/build_viewer.py --output-dir ~/ai-output gives you one page for everything the recipes made: collections, covers, search, rendered Markdown, playable games and apps, galleries and media players. It opens from disk; no server needed. See it with sample runs.

Quick start

Run a recipe

You need Python 3.10+ and Claude Code signed in, with either a Claude subscription or an ANTHROPIC_API_KEY.

bash 
$ git clone https://github.com/ai-automation-tools/ai-automation-recipes
$ cd ai-automation-recipes
$ pip install -r requirements.txt
$ cp .env.example .env          # add your image key and RECIPES_OUTPUT_DIR
$ python recipes/app-idea-card/run.py --output-dir ~/ai-output --dry-run   # print the prompt, no agent call
$ python recipes/app-idea-card/run.py --output-dir ~/ai-output             # run it for real

Schedule them

Import into Cronsole

Cronsole imports the recipes as templates, in two editions. Take everything with the ai-recipes pack, one group pack, or single templates. A template never takes a key as a parameter.

Cronsole edition

Needs Python and the agent CLI where Cronsole runs, nothing else: the first run fetches a pinned, sha256-checked runtime into your cache. Keys are optional task secrets. Best for importing and forgetting.

recipe-<name>-cronsole

Clone edition

Needs a clone of this repo and a .env. Each command is a plain command line that cron, Task Scheduler or launchd can run as it is. Best for editing prompts, or any scheduler.

recipe-<name>

The Cronsole edition is a pilot covering short-story, comics and podcast-episode. The registry README has the details.
